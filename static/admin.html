Rotate signing key

Generates a new ES256 key and promotes it to active. Previous public keys stay in the JWKS so already-issued resolve-response JWTs remain verifiable. Public JWKS: /.well-known/jwks.json.

Enter API key and click Load.

Create API key

Secret is shown only once. Store it securely. Creating keys requires the ENV API_KEY or an OIDC admin session (a PAT cannot mint more PATs).
